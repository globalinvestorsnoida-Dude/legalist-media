# legalist-media

Public image hosting for Legalist® social posts (Facebook, Instagram, LinkedIn).

- `brand/legalist-logo.jpg` — official Legalist logo (from the Legalist.in Facebook Page profile picture). Use as-is; do not recolour or redraw.
- `posts/YYYY-MM-DD/` — one folder per day:
  - `slot-08.jpg`, `slot-11.jpg`, `slot-14.jpg`, `slot-17.jpg`, `slot-20.jpg` — creatives (1080×1350 JPEG)
  - `slot-HH.json` — topic, source, captions and publishing result for that slot
  - `plan.json` — the day's ranked trending legal topics

Files here are public. Never commit anything confidential.
